2. 途中で 2 回、前処理を直した

どちらも自分の論文の主張に抵触するものだった。RNA-seq へ移すときに、マイクロアレイ用の規則をそのまま持ち込めない箇所である。

修正 1: 発現フィルタ（分位規則 → 絶対量規則）

分位規則をそのまま適用すると、中位数が TPM 0.01 付近に来て 25,046 遺伝子が残った。RNA-seq の 57,905 features には lncRNA や偽遺伝子が大量に含まれるためである。未発現遺伝子の個人間分散は測定ノイズなので、これを残すと「共発現しない」という結論が検出限界の産物になる（論文 §4.5 R3 で自ら立てた反論に抵触する）。標準規則（CPM ≥ 1 を過半数の個人で満たす）に変更し、11,623 遺伝子——主コホート（10,754）と同水準になった。

修正 2: 定量方式（TPM → TMM log-CPM）

TPM のままだと第 1 主成分が全分散の 45.3% を占め、それが各検体の平均発現量と ρ = 0.977 だった。これは「発現が何遺伝子に集中しているか」という複雑度の差であって生物学ではない。結果としてランダム対照の内部整合性が 0.168 まで底上げされていた。

比較は同じ 11,623 遺伝子・同じ 79 名に固定し、定量と正規化だけを差し替えて行った（発現フィルタの効果と正規化の効果を分離するため）。主成分の符号は数値計算上不定なので、平均発現量と正相関する向きにそろえてある。

定量方式PC1 の寄与率平均発現量との ρ検出率との ρランダム対照の整合性
TPM そのまま45.3%0.9770.6000.168
TPM + 分位正規化35.4%0.7940.5590.002
TMM log-CPM（採用）35.5%0.6260.5850.012

どの正規化でも検出率との関連は消えない（|ρ| = 0.600 / 0.559 / 0.585）。変わるのはランダム対照の水準で、0.002 から 0.168 まで 70 倍動く。つまり内部整合性の絶対値は、その研究がどの正規化を選んだかでほぼ決まる。これ自体が本研究の中心主張（絶対値ではなく対照との差で報告する）の直接的な例証になる。共発現解析の分野標準である TMM log-CPM（edgeR）を主経路にした。

訂正（2026-08-08）。以前この表は TMM の行に「検出率との ρ = −0.209、対照 0.003」と書いていたが、これは分位正規化された古い行列で測った値だった。遺伝子集合を固定して再測定した上の値が正しい。再現は pixi run wp1-normalization。

3. 結果 4（帰属）は 3 種類目の攪乱要因で再現した

精製単球では測定チップ、全血では血球組成、マクロファージでは培養状態——実験系ごとに正体は違うが、支配軸がそのセットの名乗る生物学ではない点は一貫している。

GSE81046: ラベルと遺伝子内容が対応しないセットが上位に並ぶ現象も再現

細胞種マーカーで内部整合性が高いのは Reticulocytes（0.326）・Pluripotent Stem Cells（0.301）・Undefined Placental Cells（0.192）・Spermatozoa（0.146）。これはラベルの細胞種がマクロファージに混ざっているのではなく、遺伝子内容がラベルと対応していない。Reticulocytes は翻訳と核膜孔でヘモグロビン遺伝子を 1 つも含まず、Pluripotent Stem Cells は細胞周期、Spermatozoa は C1QA/B/C・CD14・CD163 を含む初代マクロファージのプログラムである。マイクロアレイでの Hemangioblasts・Trophoblast Progenitor Cells・Reticulocytes と同じ現象が、別プラットフォーム・別細胞で再現した。整合性はラベルではなく遺伝子内容に対応する。

雑音軸（単球サブセット／血小板／赤血球／リンパ球／全遺伝子の第 1 主成分）を全部抜いたときの変化を、両プラットフォームで同じ定義で比べる。

設計した生物学でさえ、支配軸ではない

GSE81046 はアフリカ系とヨーロッパ系の免疫応答差を調べるために設計されたコホートである。にもかかわらず、祖先集団は PC1（全分散の 35.5%）の 2.0% しか説明しない（ラベル並べ替え検定 p = 0.23）。PC1〜PC5 のいずれでも説明率は 0.1〜2.9% にとどまった。

GTEx: 血球組成 > 技術 > 個人属性 が RNA-seq でも成立

755 検体・PC1〜PC5 について、ラベル並べ替えの偶然水準を引いた超過説明率を分類ごとに集計した。集計は各主成分の寄与率で重み付けしている（単純に足すと寄与率 3.3% の PC5 が 29.3% の PC1 と同じ重みになり、主成分構造の違うコホート同士を比べられなくなるため）。

2 つのコホートは同じ集計方法（寄与率で加重）で計算しており、値を直接比較できる。順序（血球組成 > 技術 > 年齢＋性別）は測定方式によらず一致する。

虚血時間は他のコホートにない軸で、死後・採取後の時間経過という「生物学とも技術ともつかない要因」である。これが PC1 の 64% を説明したことは、「支配軸はその実験系で最大の攪乱要因」という主張をさらに補強する。GTEx を個人層別化に使う研究は多いが、この軸を調整せずに個人の経路活性を語ることはできない。

4. 結果 1（乖離）は方向が再現、大きさは縮んだ

区画GSE81046（RNA-seq）主コホート（マイクロアレイ）
評価セット2,5142,195
条件効果あり88.3%90.8%
個人整合性あり（両対照）27.4%4.6%
条件効果のみ＝層別化不可64.4%86.7%
（雑音軸除去後）条件効果のみ60.5%73.4%

条件効果の割合はほぼ同じだが、整合性の合格率が 4.6% → 27.4% に上がったため乖離が縮んだ。培養マクロファージ（6 日間の in vitro 分化）の分化状態の個人差が強い共発現構造を作っているためと考えている。ただしその構造は雑音軸の除去で目減りする（regulon −40%、Reactome −27%、Hallmark −18%）ので、そのセットの生物学に帰属できる整合性とは言えない。

ファミリー順位は、サイズ帯をそろえると保たれる

データ由来モジュールが最上位（アレイ 0.364 / RNA-seq 0.370）である点は一致した。一方、ファミリーの順位そのものは、サイズ帯を混ぜると保存されない（超過分の Spearman 0.143、p = 0.79／参照アンカーを除いて +0.26）。RNA-seq では参照アンカーが第 2 位、タンパク質複合体が第 3 位に上がり、アレイで第 2 位だった細胞種マーカーが最下位に落ちる。

ただしサイズ帯をそろえると順位は保たれる。26〜60 遺伝子の帯に限ると超過分の順位相関は 0.900（p = 0.037）、整合性の中央値では 1.000 になる。11〜25 帯ではいずれも 0.800（p = 0.20、4 ファミリー）である。順位が保存されないように見えるのは、サイズ帯を混ぜたことの産物だった。対照を上回る割合はセットが大きいほど上がるので、サイズ帯をまたいでファミリーを比べると大きいセットの多いファミリーが上に来る。

訂正（2026-08-08）。以前ここには「順位相関 Spearman +0.829（p = 0.042）」と書いていたが、これは分位正規化された古い行列での値だった。正しい行列では順位は保存されない。本文の主張も「データ由来モジュール以外は対照との差が小さいか不安定」までに限定した。

更新（2026-08-24）。サイズ帯で層別した解析を入れたので、この節の結論が変わった。サイズ帯を混ぜたときの順位相関も対照 10,000 個での再計算で +0.00 から 0.143 に動いている。論文本文の該当箇所は 3.8 節。

5. 主張の書き換え

書き換え前: 条件効果があるセットの 86.7% は個人層別化に使えない
書き換え後: 条件効果はどのデータでもほぼ普遍（88〜91%）。個人整合性の割合はデータセット依存（5〜27%）。しかし「見かけの整合性の主因はセットが名乗る生物学ではない」は、4 コホート・4 種類の攪乱要因（測定チップ／血球組成／培養状態／虚血時間）で一貫して再現する。

この書き換えは論文にとって弱体化ではない。「割合」を主張の中心から外し、「帰属」を中心に据えることで、データセット依存性という反論をあらかじめ吸収できる。単一コホートの割合を売りにしていたら、査読で「別のデータでは違うのでは」と突かれて終わっていた。
